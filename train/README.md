# 训练数据放这里

把你的训练歌曲按下面的结构放进来（**每首歌一个文件夹**）：

```
train/
└── 歌曲名1/
    ├── song1.ogg        （或 .mp3）
    └── song1.adofai     （ADOFAI 谱面，作为踩点的"标准答案"）
└── 歌曲名2/
    ├── song2.mp3
    └── song2.adofai
```

说明：
- 音频和谱面必须**成对**出现（同名、不同后缀）。
- `.adofai` 是你手动打好的谱面，AI 从中学习"哪里该踩点、哪里该转圈"。
- 这些音频和谱面文件**不会**被提交到 git（已在 `.gitignore` 中排除）。
- 没有数据也能启动网页，但训练/生成会因为缺少模型权重而失败。
